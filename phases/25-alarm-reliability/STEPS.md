# Phase 25 실행 단계

1. **데이터 기반 (완료)** — 기대 발생, 전달 토큰, 관측 공백 엔티티와 DAO, 정책 및 경계 테스트.
2. **v8 통합 (에뮬레이터 검증 완료)** — 6→8과 7→8 마이그레이션에서 기존 데이터 보존과 새 테이블을 계측 테스트로 확인했다.
3. **스케줄러 연결 (코드 완료)** — 최신 Room 상태를 읽는 IO 명령 큐, 48시간 기대 집합, 고유 URI 토큰과 OS 등록 결과를 기록한다.
4. **리시버 연결 (코드 완료)** — 토큰을 확인해 발화를 기록한 뒤 알림 게시 결과를 별도로 기록하고, one-shot 알람을 재무장한다. 실제 기기 발화 순서는 검증 대기다.
5. **기대 집합 대사 (코드 완료)** — 복원 명령 완료 후 관측 범위를 갱신한다. 12시간 주기 복원, 관측 공백 보호, 유예시간 후 누락 판정, 30일 보존을 구현했다.
6. **상태 화면과 실측 (화면 완료, 실측 대기)** — 7일·30일 기록과 리마인더 참고 지표를 표시한다. 기기 실측 전 5%는 참고치다. Doze, 재부팅, 권한 변경, 콜드 스타트 A→B 순서와 48시간 창·15분/2시간 유예값을 실제 기기에서 측정한다.
