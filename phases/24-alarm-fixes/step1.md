# Step 1: scheduler-fix

## 목표

실제 Room 항목 상태에 맞게 알람을 등록하거나 취소한다. 오래된 워커 스냅샷이 새 등록을 되돌리는 경우를 줄인다.

## 구현 범위

- `AlarmScheduler`가 Step 0의 계산 결과와 Todo 마감 시각을 사용한다. 삭제·완료·과거 시각이면 기존 PendingIntent를 취소한다.
- OS 작업을 단일 명령 큐로 직렬화한다. 큐에서는 호출 시 전달받은 엔티티 스냅샷 대신 최신 Room 행을 다시 읽어 오래된 복원·동기화 입력이 새 상태를 되돌리지 않게 한다.
- 반복 일정의 마스터 알람 off + 특정 발생 on을 복원 워커 조회에 포함한다.
- 로그아웃은 원격 엔티티를 삭제하지 않고 명시적 취소를 수행한다.

## 완료 조건

- 일정/Todo 수정·삭제·완료·로그아웃 후 옛 알람이 남지 않는다.
- 발생별 제목과 시각이 실제 등록 Intent에 반영된다.
- 최신 변경 뒤 도착한 오래된 워커 입력이 알람을 되돌리지 않는다.
